ClassPulse – Class Concept Difficulty Analysis System

Project Overview

ClassPulse is a web-based academic management system that collects student feedback, identifies difficult concepts, and helps faculty improve teaching effectiveness. It also supports student management, assignment tracking, notes, reminders, and academic file sharing.

Key Features

- Student Registration and Login
- Student Feedback Submission and Analysis
- Concept Difficulty Identification
- Faculty Dashboard and Student Management
- Notes and Reminder Management
- Academic File Upload and Download

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Tools: XAMPP, phpMyAdmin
